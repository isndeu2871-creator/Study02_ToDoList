# Study02_ToDoList

하루 10~20개의 할 일을 관리하는 개인용 할 일 관리 앱입니다. PRD와 구현(`index.html`)이 들어 있습니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 실행됩니다. 설치나 빌드는 필요 없습니다.

## 앱 개요

- 브라우저에서 바로 실행되는 웹 앱 (설치·로그인 없음)
- 순수 JavaScript, 단일 HTML 파일, 외부 라이브러리 없음
- 새로고침해도 데이터가 유지됨 (`localStorage`)

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 할 일 관리 | 추가, 수정, 삭제 |
| 완료 체크 | 체크박스로 완료/미완료 전환 |
| 카테고리 | 업무 / 개인 / 공부 분류와 탭 필터 |
| 진행률 | 전체 및 카테고리별 진행률 막대와 퍼센트 |
| 부가 기능 | 완료 항목 일괄 삭제, 다크 모드(시스템 설정 따름) |

## 문서

- [index.html](index.html): 앱 전체 (HTML, CSS, JavaScript 한 파일)
- [PRD.md](PRD.md): 배경과 목표, 기능 요구사항, 데이터 모델, 화면 구성, 성공 기준, 열린 질문
- [PROMPTS.md](PROMPTS.md): PRD를 Claude Code에서 구현하기 위한 5단계 프롬프트

## 상태

PRD의 기능 요구사항(F1~F9)과 성공 기준을 모두 구현했습니다. 열린 질문 5개는 PRD의 "현재안"대로 구현했습니다(날짜 구분 없이 누적, 입력 순서 정렬, 카테고리 3개 고정, 내보내기 없음).
