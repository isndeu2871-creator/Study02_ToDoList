# Study02_ToDoList

브라우저에서 바로 실행되는 개인용 할 일 관리 앱이다. 하루 10~20개 수준의 할 일을 적어 두고, 카테고리로 나눠 보면서 완료 여부와 진행률을 확인한다.

서버도 계정도 빌드 도구도 없다. HTML 파일 하나를 브라우저로 열면 실행되고, 데이터는 브라우저의 localStorage에 남는다.

## 실행

[index.html](index.html) 하나만 있으면 된다. 파일을 브라우저로 열면 그대로 실행된다. 설치할 것도, 띄울 서버도 없다.

## 기능

- 할 일 추가, 수정, 삭제
- 완료 체크
- 카테고리 분류 (업무, 개인, 공부)와 카테고리 탭 필터
- 진행률 보기 (전체와 선택한 카테고리 기준)
- 새로고침해도 유지되는 저장
- 완료 항목 일괄 삭제, 다크 모드(시스템 설정을 따름)

## 기술 스택

- HTML, CSS, 순수 자바스크립트. 라이브러리와 프레임워크는 없다.
- HTML 하나에 CSS와 자바스크립트를 같이 담는다.
- 상태 변경은 언제나 `배열 변경 → 저장하기() → 그리기()` 순서로만 일어난다. DOM을 부분적으로 고치지 않아 화면과 데이터가 어긋나지 않는다.

## 데이터

localStorage 키 `todos`에 JSON 배열로 저장한다. 브라우저를 벗어나지 않으며 어디로도 전송되지 않는다. 브라우저마다 저장소가 따로이므로, 크롬에서 적은 할 일은 사파리에서 보이지 않는다.

구현은 끝났고, 아직 배포하지 않았다. PRD의 기능 요구사항 F1~F9를 구현했고, 자동 검사(Playwright)로 동작을 확인했다. PRD 9장의 열린 질문 5개는 "현재안"대로 정했다. 날짜 구분 없이 누적하고, 입력 순서로 보여 주고, 카테고리는 3개로 고정하고, 내보내기는 없다.
